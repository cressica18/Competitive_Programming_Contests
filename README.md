# Competitive Programming Contests

My competitive programming repository containing solutions, approaches, and weekly contest write-ups. Each write-up documents the problem statement, the logic used to solve it, and the corresponding C++ implementation.

## Repository Structure

- **Codeforces/** — Solutions and write-ups for Codeforces contests.
- **AtCoder/** — Solutions from AtCoder contests.
- **LeetCode/** — Solutions from LeetCode contests.
- **CodeChef/** — Solutions from CodeChef contests.

Each contest directory contains individual problem files, with `.cpp` files for source code and `.md` files for problem explanations and write-ups.
